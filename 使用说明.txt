Codex Home Mover 使用说明
==========================

用途
----
把 Windows 用户目录中的 .codex 整体迁移到其他 NTFS 固定磁盘，同时用
NTFS 目录联接（Junction）保留原路径。正常情况下，以前任务里的本地文件
链接不需要修改。

重要提醒
--------
1. 本工具以管理员权限运行，会修改目录结构和访问权限。
2. 查看空间、自动推荐、选择路径和预检时，不需要关闭 Codex。
3. 点击“开始迁移”前，必须保存工作并彻底退出 Codex 和 ChatGPT。
4. 迁移过程中不要关闭本程序、关机、重启或拔掉目标磁盘。
5. 不要手动删除、改名或移动源目录、目标目录、隔离目录和安全备份。
6. “释放 C 盘空间”会永久删除安全备份，不会进入回收站。
7. 本工具不能代替独立备份。特别重要的资料请先另存一份。

最简单的使用步骤
------------------
1. 完整解压 Release ZIP。CodexHomeMover.exe.config 必须和 EXE 放在一起。
2. 双击 CodexHomeMover.exe，并允许 Windows 的管理员权限提示。
3. 等待左侧“Codex 磁盘占用”完成统计。
4. 点击“自动推荐”，确认当前目录和新位置都正确。
5. 保持“逐文件 SHA-256 校验（推荐）”勾选。
6. 点击“预检”。预检只读取和检查，不会移动或修改文件。
7. 预检通过后，保存手头工作，彻底退出 Codex 和 ChatGPT。
8. 回到本程序，点击“开始迁移”，等待小鱼弹窗提示“搬家成功”。
9. 重新打开 Codex，检查历史任务、图片、附件、设计文件链接和新任务保存。
10. 确认关键内容全部正常后，再点击“释放 C 盘空间”。

什么时候必须关闭 Codex？
-------------------------
- 查看占用空间：不用关闭。
- 自动推荐和选择路径：不用关闭。
- 预检：不用关闭。
- 开始迁移：必须关闭，并保持关闭到迁移完成。
- 迁回 C 盘：必须关闭。
- 释放 C 盘空间：完成验证后，关闭 Codex 再执行。

界面功能
--------
- Codex 磁盘占用：统计实际磁盘占用、文件数和所在盘剩余空间。
- 自动推荐：自动查找 .codex，并推荐空间充足的非 C 盘 NTFS 固定磁盘。
- 预检：检查磁盘、空间、权限、进程和目录状态，不修改文件。
- 开始迁移：先复制，再执行所选校验，最后切换 Junction。
- 小鱼搬家动画：在真实进度范围内循环移动；右侧百分比才是实际进度。
- 迁回 C 盘：将数据安全迁回原磁盘，执行前必须关闭 Codex。
- 释放 C 盘空间：永久删除迁移时保留的 C 盘安全备份，需要两次确认。
- 取消：在下一个安全检查点停止，不会强行中断正在写入的单个文件。
- 打开日志：查看仅保存在本机的详细操作记录。
- 显示比例：右上角可在 80% 至 200% 之间调整。

目标磁盘要求
------------
- 建议使用电脑内部的固定磁盘。
- 文件系统必须是 NTFS。
- 目标盘必须持续在线，并保持盘符不变。
- 不要使用 exFAT、FAT32、网络盘、云同步目录或移动盘。
- 可用空间至少要大于 Codex 数据量，并留出额外余量。

迁移成功后怎样确认？
--------------------
1. Codex 能正常启动并能创建新任务。
2. 历史任务可以打开。
3. 对话中的图片、附件和本地文件可以打开。
4. 新建一个小任务，确认可以正常保存。
5. 原路径 C:\Users\你的用户名\.codex 仍然存在且可以访问。
6. 目标盘盘符没有改变。

如果迁移失败
------------
- 不要手动删除任何目录。
- 点击“打开日志”查看失败原因。
- 在最终切换前失败时，C 盘原目录仍是主数据，不会被替换。
- 复制或校验阶段失败时，可以保留目标副本；重新打开新版后，确认目标确实
  来自本工具的失败迁移，再勾选“仅用于失败后续传”并重试。
- 如果已经切换但使用异常，关闭 Codex 后点击“迁回 C 盘”。
- 如果不确定当前状态，先停止操作并保留源目录、目标目录和安全备份。

日志与隐私
----------
程序不联网，也不上传文件。日志仅保存在本机：
%LOCALAPPDATA%\CodexHomeMover\logs

日志会在 5 MB 时轮转，可能包含用户名、本地路径、文件名、进程 ID 和错误堆栈。
提交 GitHub Issue 前只复制必要的几行并脱敏。不要上传 .codex、auth.json、数据库、
完整日志或带私人路径的截图。

下载安全
--------
当前社区构建尚未进行代码签名，Windows SmartScreen 可能显示“未知发布者”。
请只从项目正式 GitHub Release 下载完整 ZIP，并核对随包发布的 SHA-256。
不要关闭 Microsoft Defender，也不要全局降低 Windows 安全设置。
